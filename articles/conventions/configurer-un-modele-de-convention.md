# Objectif

Configurer un modèle de convention personnalisé afin que les conventions de mini-stage soient générées automatiquement avec les informations de votre établissement.

---

# Prérequis

- ✅ Être connecté à Bacastages avec un compte **administrateur** ou **DDF**
- ✅ Disposer du fichier PDF de votre modèle de convention (format PDF uniquement)
- ✅ Avoir accès à la section **« Établissement »** dans le menu latéral

---

# Étapes à suivre

# 1\. Accéder à la configuration des conventions

Rendez-vous dans le menu latéral et cliquez sur **« Établissement »**, puis sélectionnez l'onglet **« Conventions »**. Vous accédez à l'interface de configuration de votre modèle de convention.

# 2\. Importer votre modèle PDF

Cliquez sur le bouton **« Importer un modèle »** et sélectionnez le fichier PDF de votre convention vierge. Le document s'affiche dans l'éditeur de convention avec un aperçu de chaque page.

# 3\. Comprendre les types de champs

L'éditeur propose trois types de champs que vous pouvez positionner sur votre convention :  
  
\- **Champs rouges** : données remplies automatiquement (nom de l'élève, dates du mini-stage, nom de l'établissement, etc.). Ces champs sont pré-remplis à partir des informations enregistrées sur Bacastages.  
  
\- **Champs verts** : images insérées automatiquement (logo de l'établissement, pré-signature du chef d'établissement). Ces éléments sont récupérés depuis les paramètres de votre établissement.  
  
\- **Champs bleus** : texte statique personnalisable. Vous pouvez y saisir du texte libre qui apparaîtra tel quel sur toutes les conventions générées.

# 4\. Positionner les champs par glisser-déposer

Sélectionnez un champ dans la liste à gauche de l'éditeur, puis **glissez-déposez**-le à l'emplacement souhaité sur le modèle PDF. Vous pouvez redimensionner chaque champ en tirant sur ses bords et le repositionner à tout moment. Répétez l'opération pour chaque champ que vous souhaitez faire apparaître sur la convention.

# 5\. Enregistrer le modèle

Une fois tous les champs positionnés, cliquez sur le bouton **« Enregistrer »** en haut à droite de l'éditeur. Votre modèle de convention est désormais actif et sera utilisé pour générer automatiquement les conventions de vos mini-stages.

---

# Résultat attendu

- Votre modèle de convention est configuré et sauvegardé
- Les conventions de mini-stage sont générées automatiquement à partir de ce modèle
- Les champs rouges sont pré-remplis avec les données de chaque mini-stage
- Le logo et la pré-signature sont insérés automatiquement si configurés

---

# Conseils pratiques

💡 Testez votre modèle en générant une convention pour un mini-stage existant afin de vérifier le positionnement de tous les champs.

💡 Pensez à configurer le logo et la pré-signature de votre établissement avant de positionner les champs verts (voir l'article « Ajouter une pré-signature et un logo »).

💡 Si votre modèle de convention change, vous pouvez à tout moment importer un nouveau PDF et repositionner les champs.
