# Objectif

Modifier les informations d'une offre de mini-stage existante ou la supprimer/dépublier si elle n'est plus d'actualité.

---

# Prérequis

- ✅ Disposer d'un compte avec le rôle DDF ou administrateur d'établissement
- ✅ Avoir créé au moins une offre de mini-stage

---

# Étapes à suivre

# 1\. Accéder à vos offres

Depuis votre espace établissement, cliquez sur **« Mes offres »** dans le menu de navigation. La page affiche la liste de toutes les offres de mini-stages que vous avez créées.

# 2\. Ouvrir l'offre à modifier

Cliquez sur l'offre que vous souhaitez modifier pour accéder à sa fiche détaillée. Cliquez ensuite sur le bouton **« Modifier »** pour accéder au formulaire d'édition.

# 3\. Modifier les informations de l'offre

Vous pouvez modifier les champs suivants :  
• **« Dates »** : ajustez les dates de début et de fin du mini-stage  
• **« Capacité »** : modifiez le nombre maximum de participants  
• **« Description »** : mettez à jour le contenu et le programme du mini-stage  
• Toute autre information relative à l'offre

# 4\. Enregistrer les modifications

Après avoir effectué vos changements, cliquez sur **« Enregistrer »** pour sauvegarder les modifications. Les participants déjà inscrits ne sont pas affectés par les modifications.

# 5\. Supprimer ou dépublier une offre

Si vous ne souhaitez plus proposer une offre :  
• **« Dépublier »** : l'offre n'apparaît plus dans les résultats de recherche, mais les pré-inscriptions existantes sont conservées  
• **« Supprimer »** : l'offre est définitivement retirée. Attention, cette action est irréversible et n'est possible que s'il n'y a aucune pré-inscription validée

---

# Résultat attendu

- Les modifications sont enregistrées et immédiatement visibles par les utilisateurs
- L'offre dépubliée n'apparaît plus dans les recherches
- L'offre supprimée est définitivement retirée de la plateforme

---

# Conseils pratiques

💡 Préférez dépublier plutôt que supprimer si vous envisagez de réutiliser l'offre ultérieurement.

💡 Si vous modifiez les dates, pensez à prévenir les élèves déjà inscrits du changement.

💡 Vérifiez qu'aucune pré-inscription n'est en attente avant de supprimer une offre.
