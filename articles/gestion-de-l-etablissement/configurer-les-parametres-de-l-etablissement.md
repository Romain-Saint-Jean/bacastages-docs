# Objectif

Configurer les paramètres généraux de votre établissement pour personnaliser le fonctionnement de Bacastages selon vos besoins.

---

# Prérequis

- ✅ Être connecté à Bacastages avec un compte **administrateur** (SCHOOL\_ADMIN)
- ✅ Avoir accès à la section **« Établissement »** dans le menu latéral

---

# Étapes à suivre

# 1\. Accéder aux paramètres

Rendez-vous dans le menu latéral et cliquez sur **« Établissement »**, puis sélectionnez l'onglet **« Paramètres »**. Les différentes options de configuration s'affichent.

# 2\. Configurer la publication automatique des annonces

L'option **« Publication automatique des annonces »** vous permet de choisir si les nouvelles annonces de mini-stage sont publiées automatiquement ou si elles nécessitent une validation manuelle avant d'être visibles.  
  
\- **Activée** : les annonces créées par les DDF et les professeurs sont immédiatement visibles par les parents et les élèves  
\- **Désactivée** : les annonces restent en brouillon et doivent être publiées manuellement par un administrateur ou un DDF

# 3\. Configurer la validation des bilans

L'option **« Validation des bilans »** vous permet de définir comment les bilans de mini-stage sont traités :  
  
\- **Automatique** : les bilans soumis par les professeurs sont automatiquement validés  
\- **Manuelle** : les bilans doivent être revus et approuvés par un administrateur ou un DDF avant d'être finalisés

# 4\. Mettre à jour la description de l'établissement

Dans la section **« Description »**, rédigez une présentation de votre établissement. Cette description peut être affichée aux parents et aux élèves qui consultent vos annonces de mini-stage. Cliquez sur **« Enregistrer »** après modification.

# 5\. Mettre à jour les informations de contact

Dans la section **« Contact »**, vérifiez et mettez à jour les informations de contact de votre établissement : adresse, numéro de téléphone, adresse email de contact. Ces informations peuvent apparaître sur les conventions et dans les communications envoyées aux familles. Cliquez sur **« Enregistrer »** pour valider.

---

# Résultat attendu

- Les paramètres de votre établissement sont mis à jour
- La publication automatique des annonces est activée ou désactivée selon votre choix
- Le mode de validation des bilans est configuré
- Les informations de contact et la description sont à jour

---

# Conseils pratiques

💡 Si votre établissement débute sur Bacastages, commencez par désactiver la publication automatique afin de vérifier les annonces avant leur mise en ligne.

💡 La validation manuelle des bilans est recommandée si vous souhaitez contrôler la qualité des retours avant leur envoi aux familles.

💡 Tenez vos informations de contact à jour : elles sont utilisées dans les conventions de mini-stage et les emails envoyés aux parents.
