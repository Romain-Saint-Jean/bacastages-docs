# Objectif

Personnaliser le contenu et le calendrier des emails de rappel envoyés automatiquement aux participants avant leurs mini-stages.

---

# Prérequis

- ✅ Être connecté à Bacastages avec un compte **administrateur** (SCHOOL\_ADMIN) ou **DDF**
- ✅ Avoir accès à la section **« Établissement »** dans le menu latéral

---

# Étapes à suivre

# 1\. Accéder à la configuration des emails de rappel

Rendez-vous dans le menu latéral et cliquez sur **« Établissement »**, puis sélectionnez l'onglet **« Emails de rappel »**. La liste des modèles d'emails de rappel disponibles s'affiche.

# 2\. Sélectionner un modèle à personnaliser

Cliquez sur le modèle d'email que vous souhaitez personnaliser. L'éditeur de contenu s'ouvre avec le texte actuel du modèle. Bacastages propose différents modèles de rappel envoyés automatiquement aux participants (rappel avant le mini-stage, confirmation d'inscription, etc.).

# 3\. Modifier le contenu de l'email

Utilisez l'éditeur de texte pour modifier le contenu de l'email de rappel. Vous pouvez :  
  
\- Modifier le **texte du message** pour l'adapter au ton de votre établissement  
\- Ajouter des **informations pratiques** spécifiques (adresse, consignes d'accueil, matériel à apporter, etc.)  
\- Utiliser les **variables dynamiques** proposées par l'éditeur pour insérer automatiquement le nom de l'élève, les dates du mini-stage, le nom de la filière, etc.

# 4\. Configurer le calendrier d'envoi

Définissez le **moment d'envoi** de chaque email de rappel. Vous pouvez choisir le nombre de jours avant le mini-stage auquel le rappel sera envoyé (par exemple, 7 jours avant, 2 jours avant, la veille).

# 5\. Enregistrer les modifications

Cliquez sur **« Enregistrer »** pour sauvegarder vos modifications. Les prochains emails de rappel seront envoyés avec le nouveau contenu et selon le calendrier défini.

---

# Résultat attendu

- Les modèles d'emails de rappel sont personnalisés selon vos besoins
- Le calendrier d'envoi est configuré
- Les prochains rappels automatiques utiliseront le contenu mis à jour

---

# Conseils pratiques

💡 Incluez des informations pratiques dans vos emails de rappel : adresse de l'établissement, horaires d'accueil, documents à apporter.

💡 Utilisez les variables dynamiques pour personnaliser automatiquement chaque email avec les informations du mini-stage concerné.

💡 Un rappel envoyé 2 à 3 jours avant le mini-stage réduit significativement les absences. Pensez à configurer au moins un rappel à cette échéance.

💡 Testez vos emails en consultant l'aperçu avant d'enregistrer vos modifications.
